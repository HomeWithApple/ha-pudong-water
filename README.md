# 浦东威立雅水费 · Home Assistant 集成

把上海浦东威立雅自来水的水费账单接进 Home Assistant：每期用水量、污水量、水费、表读数、抄表日、账户余额，并写入能源面板用的长期统计（按实际抄表日）。

非官方项目，与浦东威立雅无关。接口不公开，随时可能变；使用风险自负。

## 先知道这几件事

- **只要销根号（户号），不用密码**。用的是「浦东威立雅」微信公众号查账单时调用的接口，请求以微信内置浏览器的身份发出。
- **隐私**：这个接口只凭户号就能查到账单，返回里还带户名和地址。也就是说**户号相当于查看你家水费的钥匙**，不要随便给别人。本集成不保存、不显示户名和地址。
- **数据很粗**：两个月抄一次表，接口只给最近一年左右（约 6 期）的账单，没有每日用量。能源面板里两个月一根柱子，历史只能补一年。
- **默认 15 天查一次**（选项里可改 1～30 天）。HA 重启时用本地缓存，不重新查询；想马上更新，在任一实体上手动「更新」。

## 安装

Home Assistant 2026.2 或更新。

- **Marketplace / HACS**：添加自定义仓库 `https://github.com/HomeWithApple/ha-pudong-water`，类别「集成」，下载。
- **手动**：把 `custom_components/pudong_water/` 放到 HA 配置目录的 `custom_components/` 下，重启。

## 配置

设置 → 设备与服务 → 添加集成 → 浦东威立雅水费，填销根号。添加时会真去查一次账单。

## 能源面板

能源设置 → 水 → 添加水源，选统计「**浦东威立雅 xxxx 用水量**」；费用选「使用跟踪总成本的实体」→「**浦东威立雅 xxxx 水费**」。

两条统计都从 0 开始逐期累加（不用表读数，换表时读数会变小），点落在每期的抄表日。水费按账单应缴金额（水费 + 污水费）计，不是实际缴的钱。

## 传感器

本期用水量（属性里有近期账单）、本期污水量、本期水费合计（属性里有水费、污水费、单价）、今年水费、水表读数（属性里有抄表方式）、本期抄表日、下次抄表日、账户余额、本期实缴（属性里有缴费时间）、最近取数时间。

## 已知限制

- 接口只回最近一年左右的账单。
- 统计只往后追加；如果删掉过统计，下次会从接口还查得到的最早一期重新开始。
- 账户余额的正负含义（预存还是欠费）没有核实过，按接口原值显示。
